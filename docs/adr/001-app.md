# ADR-001 — Công nghệ app

- **Trạng thái:** đề xuất, chờ chủ dự án ghi "đồng ý" (P0-T06)
- **Ngày:** 2026-10-28
- **Nguồn:** BACKBONE C-01; SDD monolith ADR-M01, §11

## Bối cảnh

- 1 GV, 1 máy, không đăng nhập (NFR1).
- 11 màn hình đã có trong bản nháp `docs/prototype/` (HTML + JS thuần, chạy được ở 390 px).
- Graph, agent, schema viết bằng Python.

## Quyết định

| Phần | Chọn |
|---|---|
| Backend | Python 3.12, FastAPI + uvicorn, 1 worker, chỉ nghe `127.0.0.1` |
| Frontend | HTML + JS thuần + MathJax 3.2.2; shell lấy từ `docs/prototype/src/shell.html` → `app/index.html`; `app/api.js` thay `MOCK` bằng gọi `/api` |
| Mở app | `uv run tutor app` → mở trình duyệt |

## Phương án đã bỏ

| Phương án | Vì sao bỏ |
|---|---|
| App desktop (Electron, Tauri) | Phải đóng gói theo hệ điều hành; không thêm gì cho 1 máy local |
| Streamlit / Gradio | Không dựng lại được 11 màn hình đã thiết kế |
| SPA (React, Vue) | Thêm bước build; bản nháp JS thuần đã đủ |

## Hệ quả

- Font (Google Fonts) và MathJax nạp từ CDN: cần mạng, như khi gọi Anthropic API.
- Điện thoại / máy tính bảng: chưa hỗ trợ (§11.1 câu 7 còn mở).
